# ModernWebsByAdam — Static site

This is a small static homepage for ModernWebsByAdam. It contains:

- `index.html` — the homepage
- `style.css` — styles and responsive layout
- `script.js` — small interactive helpers (mobile nav + reveal on scroll + year)

To view locally, open `index.html` in your browser. For a better development experience run a simple static server, for example:

    # macOS / zsh
    python3 -m http.server 8000

Then open http://localhost:8000 in your browser.
